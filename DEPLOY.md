# Как выложить игру (для теста 10–20 друзей → потом тысячи)

Коротко: **сейчас не нужен большой сервер.**  
10–50 человек спокойно живут на бесплатном/дешёвом хостинге.  
Тысячи — когда игра «зайдёт» и купишь нормальный VPS (~500–2000₽/мес).

---

## Схема (одна на всю жизнь)

```
Телефоны друзей  →  сайт (кнопки, карты)  →  API+WebSocket (логин, сейв, комнаты PvP)
```

- **Сайт** — бесплатно почти везде (Cloudflare Pages / Netlify).
- **API** — нужен хост с **WebSocket** (комнаты боя). Бесплатный старт: **Render** free / **Railway** trial.

Архитектура та же при 10 и при 10 000 игроках. Меняется только железо и база (сейчас `users.json` в памяти — для теста ок).

---

## Этап 0 — проверить у себя (0₽)

```bash
npm install
cd server && npm install && cd ..
npm run dev
```

- Ты: http://127.0.0.1:5173  
- Друг в той же Wi‑Fi: `http://ТВОЙ-IP:5173` (firewall разрешить 5173 и 8787).

Так можно позвать 2–5 человек дома. В интернет «с улицы» так не отдашь.

## Этап 1 — тест 10–20 человек бесплатно (рекомендую)

### 1) API на Render (бесплатный Web Service)

1. Залей проект на GitHub.
2. [render.com](https://render.com) → New → Web Service → этот репозиторий.
3. Root Directory: `server`
4. Build: `npm install`
5. Start: `npm start`
6. Instance: Free.

Получишь URL вида `https://orakul-api.onrender.com`.

**Важно:** free Render засыпает без трафика (~15 сек «пробуждения»). Друзьям: «открой ссылку, подожди 20 сек, обнови». Для теста нормально.

### 2) Сайт на Cloudflare Pages (бесплатно)

1. Cloudflare Pages → подключить тот же GitHub.
2. Build command: `npm install && npm run build`
3. Output: `dist`
4. Environment variable при сборке:

```
VITE_API_URL=https://orakul-api.onrender.com
```

(подставь свой URL API **без** слэша в конце)

5. Deploy → получишь `https://orakul-xxxx.pages.dev`.

### 3) Скинуть друзьям

1. Ссылка на сайт.
2. Регистрация → Мультибои → код комнаты.
3. Оба нажали «Готов» → бой с телефона в браузере (Chrome / Safari).

«Установить как приложение»: в браузере «На экран Домой» — откроется почти как приложение (PWA).

## Этап 2 — стабильнее (когда надоест sleep Render)

Когда 10–20 человек уже играют и бесит ожидание:

| Что | Зачем | Порядок цены |
|-----|--------|--------------|
| Render Starter / Railway | API не засыпает | ~$5–7/мес |
| Тот же Cloudflare Pages | сайт | 0₽ |
| Бэкап `server/data` | не потерять аккаунты | диск хоста / Git LFS |

Для 50 одновременных дуэлей этого хватает с запасом (комнаты в памяти, лёгкий JSON).

## Этап 3 — тысячи игроков (потом)

Не делай сейчас. Когда припрёт:

1. VPS (Timeweb / Hetzner / Selectel) 2–4 CPU, 4–8 GB.
2. База: Postgres вместо `users.json`.
3. Несколько инстансов API + Redis для комнат (если нужно несколько серверов).
4. CDN для картинок карт.

Код боя и лобби **не переписываем с нуля** — только хранилище и железо.

## Чеклист перед тестом с друзьями

- [ ] API открывается в браузере (хотя бы ответ/лог без 502).
- [ ] В билде сайта верный `VITE_API_URL`.
- [ ] Два телефона: два аккаунта → одна комната → оба Ready → ходы видны.
- [ ] Если «нет связи» — чаще всего забыли `VITE_API_URL` или API спит (Render free).

## Защита (что уже вшито)

Игра рассчитана на то, что кто-то полезет чинить DevTools / слать кривые пакеты.

**Сервер API**
- Rate limit на `/api`, отдельные лимиты на логин/регистрацию/сейв.
- Антибрутфорс пароля (блок на минуту после кучи фейлов).
- Санитизация имени, героя, сейва: потолки золота/алмазов/уровня, нельзя телепортировать валюту одним запросом.
- Атомарная запись `users.json` + бэкапы + отказ обнулить базу.
- `uncaughtException` / `unhandledRejection` логируются — процесс не умирает от одной ошибки.

**PvP WebSocket**
- Только залогиненные; колода только из известных карт; лимит размера пакета.
- Лимит сообщений на сокет и комнат на сервер; GC мёртвых комнат.
- Ходы: typed-actions через движок **или** `commitState` с анти-чит проверкой (мана/HP/урон/победа/статы юнитов). Бог-режим и чужой ход режутся.
- Ошибка хода → клиенту error + честный стейт, комната жива.
- **Таймер хода 20с** → авто-передача хода; **5 пропусков** у одного = кик и поражение, сопернику победа.
- **Выход / обрыв связи** в бою = поражение вышедшему, победа оставшемуся.

**Клиент**
- `ErrorBoundary`: белый экран не вешает всю вкладку — «попробовать снова / перезагрузить».
- Падения в apply хода / send не роняют бой.

**Сообщество (меню → «Чат»)**
- Лобби-чат `/ws/chat`: хвост ~80 сообщений, без ссылок, rate limit, жалоба ПКМ.
- «Разработчику» → `server/data/feedback.jsonl` (до 5 писем/сутки).
- `lastLoginAt`; 90 дней без входа → флаг `dormant` (аккаунт не удаляем).
- Чат-лог старше 14 дней подчищается.

**Админка** (в меню кнопки нет — никто не видит)
- Открыть: в адресной строке допиши `#ora-admin` (пример: `https://твой-сайт/#ora-admin`).
- Ключ: env `ORACUL_ADMIN_KEY` или `server/data/admin.key` (в консоли API при старте). В игре ключ не показывается.
- Начислить золото/алмазы, мут чата, жалобы/фидбек. Гранты через `pendingGrants`.

**Честно:** соло на своём телефоне всё ещё можно «сломать» себе удовольствие (это клиентский движок). **Сетевой PvP и сейв на сервере** — то, что режет долбоёбов. Полная серверная симуляция каждого скилла — следующий уровень, когда попрёт рейтинг.
