# Might of Orakul

Карточные дуэли пяти фракций. Клиент — Vite/React (ПК в браузере и будущий Telegram Mini App). Аккаунты и профиль — небольшой Node API в `server/`.

## Запуск

```bash
npm install
cd server && npm install && cd ..
npm run dev
```

- Веб: http://127.0.0.1:5173  
- API: http://127.0.0.1:8787  

Опционально создай `.env` (см. `.env.example`):

```
VITE_API_URL=http://127.0.0.1:8787
```

Отдельно: `npm run dev:web` или `npm run dev:server`.

## Аккаунт и режимы

1. Регистрация / вход (логин + пароль).
2. Онбординг: выбор оракула + имя.
3. Меню: **Одиночная игра** (тропа / арена), **Мультибои** (живой PvP по коду + бот), кабинет / магазин.

Профиль и прогресс (`owned`) хранятся на сервере в `server/data/users.json` (пароли — bcrypt). Токен сессии — в `localStorage`.

## Живой бой с другом (PvP)

1. Оба запускают игру (один сервер API+WS на `:8787`, веб на `:5173` или общий хостинг).
2. **Мультибои** → **Создать комнату** → скинуть код другу.
3. Друг: **Войти по коду** → оба жмут **Готов** → бой.
4. WebSocket: `ws://…:8787/ws/pvp` (через Vite proxy `/ws` локально).

Награды за победу/поражение — как в бою с ботом (опыт и золото).

## Telegram Mini App (подготовка)

В `index.html` подключён `telegram-web-app.js`. Если клиент открыт внутри Telegram и есть `initData` / пользователь, клиент вызывает `POST /api/telegram-auth` и получает сессию (dev-заглушка без полной HMAC-проверки `initData`).

Когда появится HTTPS-хост:

1. В [@BotFather](https://t.me/BotFather) → Bot → **Bot Settings** → **Menu Button** / **Configure Mini App**.
2. Укажи **Web App URL** на собранный фронт (например `https://your-domain/`).
3. API должен быть доступен с того же origin или с CORS; задай `VITE_API_URL` на публичный URL сервера.
4. Позже: валидировать `initData` по секрету бота на сервере вместо текущей заглушки.

На ПК без Telegram по-прежнему работает логин/пароль.
